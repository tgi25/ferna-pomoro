## What's new in 1.7.0

### The ultra-compact overlay

Working full screen hides the taskbar, and with it the countdown. This is the
answer: **the focus time and the time of day, nothing else**, floating above
whatever is on screen.

- **Two layouts** — *stacked*, with the clock in smaller type under the
  countdown, or *side by side*.
- **Any size** — one slider from 60% to 250%. The window and both numbers scale
  together, so the proportions never change.
- **Stays on top** of full-screen windows, at the same level the break windows
  use. (A game in exclusive full-screen mode can still cover it; nothing running
  in Windows can sit above that.)
- Turning it on parks it in the bottom-right corner, just above the taskbar.
  Drag it anywhere from there.
- A thin line along the bottom carries the phase colour — red focus, green
  break, blue long break, amber paused.
- At rest it shows only the two numbers. Hover it for start/pause, open and
  hide; double-click to open the main window.

Turn it on in **Settings → Mini timer → Ultra-compact overlay**, with the layout
and size right underneath. `Ctrl+Alt+M` shows and hides it as before.

## Installing or updating

1. Download **Ferna-Pomoro-Setup-1.7.0.exe** below.
2. **Already have Ferna Pomoro?** Quit it first: right-click its tray icon (near
   the clock) and choose **Quit**. Closing the window only hides it.
3. Run the installer. If Windows says *"Windows protected your PC"*, click
   **More info → Run anyway**. The installer isn't code-signed.
4. It updates the existing app in place. Your statistics, tasks and settings are
   kept, so you don't need to uninstall the old version first.
5. Check it: **Settings** should say **Ferna Pomoro 1.7.0** at the bottom.

Prefer not to install? **Ferna-Pomoro-Portable-1.7.0.exe** runs without
installing. Windows 10 or 11, 64-bit.

To verify a download, compare it with `SHA256SUMS.txt`:
`Get-FileHash .\Ferna-Pomoro-Setup-1.7.0.exe -Algorithm SHA256`
