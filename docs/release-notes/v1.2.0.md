## What's new in 1.2.0

**"You haven't started work yet."** When a break ends and your next focus
session still hasn't started after a set time, a full-screen window like the
break window comes up. It shows how long ago the break ended, with three buttons:
**Start focus now**, **Remind me in N min** (or Esc) and **Stop the timer**.
It waits while you are away from the computer. Set it up in
**Settings → After a break**: on/off, the delay (1–120 minutes, default 5), and a
**Preview** button.

Also fixed:
- **+5 min break** on the break-over alert now gives you five more minutes of
  break. Before, it did nothing.
- **Show break screen** no longer appears after the break has ended.
- A finished break no longer shows as `+00:00` overtime.

## Installing or updating

1. Download **Ferna-Pomoro-Setup-1.2.0.exe** below.
2. **Already have Ferna Pomoro?** Quit it first: right-click its tray icon (near
   the clock) and choose **Quit**. Closing the window only hides it.
3. Run the installer. If Windows says *"Windows protected your PC"*, click
   **More info → Run anyway**. The installer isn't code-signed.
4. It updates the existing app in place. Your statistics, tasks and settings are
   kept, so you don't need to uninstall the old version first.
5. Check it: **Settings** should say **Ferna Pomoro 1.2.0** at the bottom.

Prefer not to install? **Ferna-Pomoro-Portable-1.2.0.exe** runs without
installing. Windows 10 or 11, 64-bit.

To verify a download, compare it with `SHA256SUMS.txt`:
`Get-FileHash .\Ferna-Pomoro-Setup-1.2.0.exe -Algorithm SHA256`
