## What's new in 1.6.0

### The mini timer

It now shows **the task you are working on** and **the time of day**, and
**Settings → Mini timer** lets you shape it:

- **Size**: small, medium or large — the window itself is resized, not just the
  text, and it shrinks further when you turn a row off.
- **Opacity**: 30–100%, for a see-through timer that doesn't hide what's behind it.
- **Keep it on top of other windows**: turn it off and other apps can cover it.
- **Give it a taskbar button**: it then behaves like any ordinary window, with a
  **–** to minimise it out of the way instead of having it float over your work.

### Backups

**Settings → Your data → Back up to a file…** writes your settings, tasks,
session log and daily totals to a single `.json` file.

**Restore from a backup…** reads one back. It first tells you what the file
holds — when it was taken, from which version, how many days, hours, pomodoros,
sessions and tasks — then asks:

- **Merge with what is here**: adds days, sessions and tasks this machine is
  missing, keeps your current settings, and never counts a day twice.
- **Replace everything**: settings, tasks and history all become the file's.

Updating Ferna Pomoro never touches your data, so this is for a new computer, a
reinstalled Windows, or peace of mind.

### Statistics

Today's sessions now scroll inside their own box, with the column headers
pinned, so a long day no longer pushes the rest of the pane down.

## Installing or updating

1. Download **Ferna-Pomoro-Setup-1.6.0.exe** below.
2. **Already have Ferna Pomoro?** Quit it first: right-click its tray icon (near
   the clock) and choose **Quit**. Closing the window only hides it.
3. Run the installer. If Windows says *"Windows protected your PC"*, click
   **More info → Run anyway**. The installer isn't code-signed.
4. It updates the existing app in place. Your statistics, tasks and settings are
   kept, so you don't need to uninstall the old version first.
5. Check it: **Settings** should say **Ferna Pomoro 1.6.0** at the bottom.

Prefer not to install? **Ferna-Pomoro-Portable-1.6.0.exe** runs without
installing. Windows 10 or 11, 64-bit.

To verify a download, compare it with `SHA256SUMS.txt`:
`Get-FileHash .\Ferna-Pomoro-Setup-1.6.0.exe -Algorithm SHA256`
