## What's new in 1.3.0

Two new full-screen windows, like the break window. You can switch each one off
in **Settings → Reminder windows**.

**Time to start work.** When you switch on the computer (or it wakes from sleep,
or you open Ferna Pomoro) and nothing has started after a set time (5 minutes by
default), a window reminds you to start. It shows **Start focus now**, **Remind me
in N min** and **Not today**.
It needs Ferna Pomoro to start with Windows. If that's off, Settings shows a
one-click **Turn it on** button.

**Session complete.** At the end of every focus session and every break, a window
says what just finished and shows today's progress. It offers:
- after focus: **Start the break**, **Start another focus session**, or **Close**;
- after a break: **Start focus**, **5 more minutes of break**, or **Close**.

Close leaves the timer waiting, and you can decide later. If the next phase starts
by itself, the break window shows a "✓ Focus session complete" line instead.

**Settings → Reminder windows** now holds all three reminders, including 1.2.0's
"You haven't started work yet". Each has a switch, a delay and a **Preview**
button.

## Installing or updating

1. Download **Ferna-Pomoro-Setup-1.3.0.exe** below.
2. **Already have Ferna Pomoro?** Quit it first: right-click its tray icon (near
   the clock) and choose **Quit**. Closing the window only hides it.
3. Run the installer. If Windows says *"Windows protected your PC"*, click
   **More info → Run anyway**. The installer isn't code-signed.
4. It updates the existing app in place. Your statistics, tasks and settings are
   kept, so you don't need to uninstall the old version first.
5. Check it: **Settings** should say **Ferna Pomoro 1.3.0** at the bottom.

Prefer not to install? **Ferna-Pomoro-Portable-1.3.0.exe** runs without
installing. Windows 10 or 11, 64-bit.

To verify a download, compare it with `SHA256SUMS.txt`:
`Get-FileHash .\Ferna-Pomoro-Setup-1.3.0.exe -Algorithm SHA256`
