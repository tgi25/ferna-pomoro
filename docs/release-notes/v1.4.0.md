## What's new in 1.4.0

**The time, large enough to read.** The taskbar button's own icon now shows the
minutes left, in big white digits on a **cat face** coloured by the phase:
- red: focus;
- green: short break;
- blue: long break;
- amber: paused;
- ✓: the session is done.

This is the biggest number Windows lets an app put on the taskbar. When nothing
is running, the normal app icon comes back.

The **tray icon** (next to the clock) takes the same cat shape, with larger
digits than before. Windows keeps tray icons at 16 px, so for the clearest view
look at the taskbar button.

Change it in **Settings → Taskbar & tray**: turn the button countdown on or off,
and choose **Cat face** or **Circle** for both icons.

## Also in this release (from 1.3.0)

**Time to start work.** After you switch on the computer (or it wakes, or you
open Ferna Pomoro), if nothing has started within a set time (5 minutes by
default), a full-screen window reminds you. It shows **Start focus now**,
**Remind me in N min** and **Not today**. It needs Ferna Pomoro to start with
Windows, and Settings offers a one-click switch.

**Session complete.** At the end of every focus session and break, a full-screen
window shows what finished. It offers the break or focus that comes next, the
alternative, or **Close**.

Both have switches in **Settings → Reminder windows**, along with the after-break
reminder from 1.2.0.

## Installing or updating

1. Download **Ferna-Pomoro-Setup-1.4.0.exe** below.
2. **Already have Ferna Pomoro?** Quit it first: right-click its tray icon (near
   the clock) and choose **Quit**. Closing the window only hides it.
3. Run the installer. If Windows says *"Windows protected your PC"*, click
   **More info → Run anyway**. The installer isn't code-signed.
4. It updates the existing app in place. Your statistics, tasks and settings are
   kept, so you don't need to uninstall the old version first.
5. Check it: **Settings** should say **Ferna Pomoro 1.4.0** at the bottom.

Prefer not to install? **Ferna-Pomoro-Portable-1.4.0.exe** runs without
installing. Windows 10 or 11, 64-bit.

To verify a download, compare it with `SHA256SUMS.txt`:
`Get-FileHash .\Ferna-Pomoro-Setup-1.4.0.exe -Algorithm SHA256`
